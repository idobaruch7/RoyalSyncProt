יום 5 — Broadcasting ו-private state

ארבע פונקציות: _broadcast_game_state, _send_private_hands, _send_private_hand, _notify_current_player. השאלה המרכזית: למה חלק מהדאטה הולך לכולם, וקלפי ה-hole הולכים רק ל-socket אחד?

כלל: state ציבורי משודר עם socketio.emit(event, data) (בלי to=) — מגיע לכל ה-sockets המחוברים. מידע פרטי נשלח עם socketio.emit(event, data, to=sid) — מגיע ל-socket יחיד. אין "חדרים" (rooms) כאן; ההפרדה היא פשוט האם יש to= או אין.

שתי רמות של נראוּת

מהמי רואהEventאיך נשלח
pot, community cards, סטאק של כל שחקן, של מי התור, מי עשה fold כולם (host + כל השחקנים)game_state socketio.emit(...) — broadcast
שני קלפי ה-hole שלךאתה בלבדyour_hand socketio.emit(..., to=player.sid)
אילו כפתורים להפעיל עכשיו (call/raise/check), min/max raise השחקן שתורו כרגע בלבדyour_turn socketio.emit(..., to=player.sid)
למה בכלל להפריד? ה-host projector מוקרן על מסך גדול שכולם רואים. אם קלפי ה-hole היו ב-game_state, כל השולחן היה רואה את היד של כל אחד. ההפרדה היא כלל המשחק, לא רק ניקיון קוד.

1. _broadcast_game_state — ה-snapshot הציבורי

event: "game_state" → כל ה-sockets 
def _broadcast_game_state():
    if current_game:
        socketio.emit('game_state', current_game.to_dict())   # אין to= -> broadcast לכולם

הפונקציה עצמה טריוויאלית. כל האינטליגנציה נמצאת ב-current_game.to_dict() — היא זו שמחליטה מה ציבורי.

Game.to_dict(for_sid=None) ב-game_engine.py:517

def to_dict(self, for_sid=None) -> dict:
    current = self._current_player()
    players_out = []
    for i, p in enumerate(self.players):
        entry = {
            'nickname': p.nickname, 'chips': p.chips, 'bet': p.bet,
            'round_bet': getattr(p, 'round_bet', 0),
            'folded': p.folded,
            'all_in': p.chips == 0 and not p.folded,
            'is_connected': getattr(p, 'is_connected', True),
            'is_bot': getattr(p, 'is_bot', False),
            'personality': getattr(p, 'personality', None),
            'is_dealer': i == self.dealer_index,
            'is_sb': i == self.small_blind_index,
            'is_bb': i == self.big_blind_index,
            'is_current': current is not None and p is current,
        }

        show_hand = (
            self.state == GameState.SHOWDOWN and not p.folded        # 1: showdown -> כולם רואים
        ) or (
            for_sid is not None and hasattr(p, 'sid') and p.sid == for_sid   # 2: זה אתה
        )
        if show_hand:
            entry['hand'] = [c.to_dict() for c in p.hand] if p.hand else []
            if p.hand and self.community_cards and self.state == GameState.SHOWDOWN:
                val = best_hand_value(p.hand + self.community_cards)
                entry['hand_name'] = HAND_NAMES.get(val[0], 'High Card')

        players_out.append(entry)

    out = {
        'state': self.state.value,
        'community_cards': [c.to_dict() for c in self.community_cards],
        'pot': self.pot,
        'pots': [ {'amount': pot['amount'], 'eligible_count': len(pot['eligible'])}
                  for pot in self._build_pots() ],
        'current_bet': self.current_bet,
        'min_raise': self.min_raise,
        'players': players_out,
        'current_player': current.nickname if current else None,
        'dealer': self.players[self.dealer_index].nickname,
    }
    ...
    return out
  • ברירת מחדל: אף שחקן לא מקבל שדה 'hand' — כל הרשומות הן ציבוריות בלבד (chips, folded, whose-turn).
  • show_hand מתווסף בשני מקרים בלבד:
    1. showdown — היד הסתיימה, הקלפים נחשפים לכולם (רק של מי שלא עשה fold).
    2. for_sid תואם — קוראים ל-to_dict עבור socket ספציפי, אז אותו שחקן מקבל את הקלפים שלו בתוך ה-payload.
שים לב לשני קוראים שונים: _broadcast_game_state קורא to_dict() בלי ארגומנט → 0 ידיים גלויות (מחוץ ל-showdown). אבל _emit_session_state (ב-reconnect) קורא to_dict(for_sid=player.sid) → לשחקן החוזר מוזרקות הידיים שלו ישירות לתוך ה-snapshot, כדי שלא יצטרך your_hand נפרד.

2. _send_private_hands / _send_private_hand

event: "your_hand" → socket יחיד לכל שחקן 
def _send_private_hands():
    if not current_game:
        return
    for player in session_to_player.values():
        _send_private_hand(player)              # אחד-אחד, כל אחד ל-socket שלו

def _send_private_hand(player):
    if not player.sid or not player.hand:       # בוט (אין sid) או עוד לא חולקו קלפים -> דלג
        return
    socketio.emit('your_hand',
                  {'hand': [card.to_dict() for card in player.hand]},
                  to=player.sid)                # ה-to= זה כל העניין
  • נקרא פעם אחת אחרי start_hand() ואחרי כל next_hand() — כלומר בכל פעם שמחלקים קלפים חדשים.
  • לולאה על session_to_player ולא על current_game.players כי אנחנו צריכים את מיפוי ה-session; שתי הרשימות זהות בתוכן.
  • בוטים מדולגים אוטומטית — ל-BotPlayer אין sid, אז _send_private_hand יוצא מיד. הבוט קורא את הקלפים שלו ישירות מ-player.hand בזמן ההחלטה.
  • שחקן offline — player.sid הוא None, אז גם הוא מדולג. כשהוא יחזור, _emit_session_state ישלח לו את היד דרך to_dict(for_sid=...) וגם _send_private_hand.

3. _notify_current_player — ה-prompt הפרטי "התור שלך"

event: "your_turn" → socket אחד: השחקן הנוכחי 
def _notify_current_player():
    if not current_game:
        return
    player = current_game.current_player()
    if player is None or player.sid is None:      # בוט או offline -> אין למי לשלוח prompt
        return
    socketio.emit('your_turn', {
        **current_game.legal_actions_for(player),  # can_check, can_raise, min_raise, max_raise, call_amount...
        'big_blind': current_game.big_blind,
        'pot': current_game.pot,
    }, to=player.sid)
  • שולח רק לשחקן שתורו עכשיו. אף אחד אחר לא צריך את הכפתורים.
  • legal_actions_for(player) מחשב בשרת אילו פעולות חוקיות (אי אפשר check מול bet, גובה raise מינימלי, וכו') — ה-client לא צריך להכיר את חוקי הפוקר, הוא רק מצייר את מה שהשרת התיר.
  • נקרא מ-_process_automatic_turns כשהראש בתור הוא אדם מחובר, ומ-_apply_and_advance אחרי invalid_action (כדי לבקש שוב מאותו שחקן).
  • Guard player.sid is None: אם התור הגיע לבוט או ל-offline, לא שולחים כלום — _process_automatic_turns כבר מטפל בהם דרך _schedule_bot_turn או auto check/fold.

איך שלושתן משתלבות ב-start_hand

# מתוך on_start_game / on_next_hand:
_broadcast_game_state()      # ציבורי -> כולם: הודעה שהיד התחילה, מי ה-dealer, גובה ה-blinds
_send_private_hands()        # פרטי  -> לכל שחקן: שני הקלפים שלו
_process_automatic_turns()   # -> בסופו קורא _notify_current_player() לשחקן הראשון לפעול (אם אדם)

הסדר חשוב: קודם ה-state הציבורי (המסך מתעדכן), אחר כך הקלפים הפרטיים (כל אחד רואה את היד שלו), ורק אז ה-prompt לפעולה.

בדיקה עצמית

  1. איך game_state מגיע לכל השחקנים בלי rooms? socketio.emit ללא to= משדר לכל ה-sockets המחוברים.
  2. למה קלפי hole לא ב-game_state? ה-host projector ציבורי; כל השולחן היה רואה כל יד. to_dict() בלי for_sid משמיט אותם.
  3. מתי כן רואים ידיים בתוך game_state? ב-showdown (של מי שלא folded), או כשקוראים to_dict(for_sid=X) עבור אותו שחקן.
  4. למה _send_private_hand לא שולח לבוטים? אין להם sid; הם קוראים player.hand ישירות.
  5. מה _notify_current_player שולח שאין ב-game_state? legal_actions_for — אילו כפתורים להפעיל ומגבלות raise, מחושב בשרת.
"ציבורי = socketio.emit בלי to=. פרטי = עם to=sid. game_state משודר לכולם ומשמיט קלפי hole חוץ מ-showdown; your_hand שולח לכל שחקן את הקלפים שלו ל-socket שלו; your_turn שולח לשחקן הנוכחי בלבד את הכפתורים החוקיים שהשרת חישב."
